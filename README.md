# Convex Cursor Rules Skill

Cursor Agent Skill with Convex guidelines and best practices. Synced from [Convex's official convex_rules.mdc](https://convex.link/convex_rules.mdc) via GitHub Actions (weekly + manual).

Use when working on Convex projects: schema design, queries, mutations, actions, HTTP endpoints, file storage, scheduling, etc.

## Usage

Add as a submodule to Convex projects:

```bash
git submodule add https://github.com/LeeorNahum/convex-cursor-rules-skill.git .cursor/skills/convex-rules
```

## Sync

The `SKILL.md` is updated weekly from Convex's source. Trigger manually via **Actions** → **Sync upstream from Convex** → **Run workflow**.
